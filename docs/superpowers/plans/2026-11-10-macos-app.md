# Native macOS Application Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a native macOS application bundle (`Enigma Terminal.app`) for macOS 26.0 and above.

**Architecture:** A lightweight native Swift / AppKit desktop wrapper embeds WebKit's `WKWebView`, serving bundled local assets via a custom URL scheme handler (`enigma://app/`). Native menus, window controls, and keyboard shortcuts integrate seamlessly with macOS while preserving 100% of the game engine's functionality.

**Tech Stack:** Swift 6, AppKit, WebKit, macOS SDK 26.0+, Python 3 (for test verification), Bash.

**Spec:** `docs/superpowers/specs/2026-11-10-macos-app-design.md`

## Global Constraints

- Target OS version: macOS 26.0 and above (`LSMinimumSystemVersion = 26.0`).
- Target architecture: arm64 / universal macOS binary.
- Bundle Identifier: `com.enigmaterminal.app`.
- No external HTTP daemon required: assets must be served internally via `WKURLSchemeHandler` (`enigma://app/`).
- Hardened runtime and App Transport Security must allow connections to `mempool.space`, `blockstream.info`, `blockchain.info`.

## Review Focus

1. Asset paths containing spaces, query params, or hash fragments must resolve correctly in `WKURLSchemeHandler`.
2. ES Module JavaScript scripts (`<script type="module">`) must load with MIME type `application/javascript` or WebKit rejects them.
3. Web Workers (like `nameforge-worker.js`) must be allowed and functional under the custom scheme.
4. `localStorage` data must persist across application restarts.
5. Missing files requested via `enigma://app/*` must return a proper 404 HTTP status rather than hanging the webview task.
